# GPT · Codex Town｜星糖庄园

**一个用于可视化本机 GPT/Codex 任务、启用自动化、近期过程与待审成果的 macOS 3D 桌面伴侣。**

Codex Town 把本机可读取的任务状态呈现在 3D 小城中：工坊对应当前工作，自动化有各自的小院，过程卡展示最近可见进展，礼盒等待你明确审阅。应用界面目前为中文。

它是本机优先的个人伴侣应用，不会执行任务、发送消息或上传数据。Codex Town 是独立项目，与 OpenAI 不存在隶属、认可或赞助关系。

> English: [README.md](README.md)

## 为什么值得使用？

- **一眼了解工作状态。** 将本机任务和自动化状态变成桌面上的 3D 城市，但不会把已启用计划误说成正在运行。
- **让验收保持明确。** 阅读成果不等于验收；验收始终是你主动执行的本机操作。
- **有限而诚实的过程信息。** 过程卡只展示最近一轮本机日志中的公开进展和工具类别，最多 12 项；不会展示模型思考、提示词、命令参数、工具输出或完整执行记录。
- **如实呈现云端边界。** 云端计划和结果是人工采集的快照，并非实时同步；云端执行过程不可读。

## 功能一览

| 模块 | 作用 |
| --- | --- |
| 3D 小城 | 在同一场景中呈现集中工坊、启用自动化小院、成果馆、运输轨道和程序化庄园主人。 |
| 本机任务 | 以只读方式读取本机可访问的 Codex 任务和自动化状态。 |
| 自动化小院 | 每个启用自动化 ID 对应一个小院；暂停和历史计划会从当前视图隐藏，但不会被删除。 |
| 过程卡 | 显示最近可见本机轮次的状态、时间，以及最多 12 项公开进展或工具类别。 |
| 待审成果 | 支持阅读、明确验收和恢复待验收；阅读不等于验收。 |
| 云端快照 | 显示带时间戳的人工导入计划和结果快照，并如实提示过期或不可用状态。 |

## 快速开始

**环境要求：** macOS 13+、Apple Silicon、Python 3.9+、Node.js 和 Xcode Command Line Tools。

```zsh
git clone https://github.com/ppdbxdawj/gpt-codex-town.git
cd gpt-codex-town
npm ci --ignore-scripts
npm run prepare:vendor
zsh desktop/build-app.sh
open 星糖庄园.app
```

项目级 `.npmrc` 固定使用 npm 公共源。`prepare:vendor` 会重建本地 Three.js 运行时及其第三方通知；打包脚本会生成并临时签名原生应用。

## 数据边界

- 本机 Codex 数据只读。
- 云端计划和结果为可选的人工导入快照，不代表实时或完整的云端同步。
- 自动化展示的本机过程按任务引用关联，不能证明这次运行由该自动化触发。
- 成果、已读状态和验收记录保存在本机；应用不会自动验收任何结果。
- 默认庄园主人是程序化角色。个人模型、贴图、任务日志、数据库、截图和私有快照均不包含在本仓库中。
