# 纯城市迷你模式 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 交付一个全窗口 3D 纯城市迷你模式，在紧凑窗口中呈现可信的工作、自动化和待审成果状态。

**Architecture:** `app.js` 在迷你模式只装配城市气泡、浮动控制与建筑 popover；`scene.js` 继续消费既有状态，不创建第二套数据源。原生壳把迷你窗口约束为适合城市查看的尺寸；5 秒状态刷新、原任务打开和完整模式保留。

**Tech Stack:** Three.js、原生 JavaScript/CSS、Swift Cocoa/WebKit、既有本地 JSONL 服务。

---

### Task 1: 迷你模式信息模型与测试

**Files:**
- Modify: `public/app.js`
- Test: `tests/test_schedule_village.mjs` 或新增纯 helper 测试

**Step 1:** 为工坊生成 `running`、`waiting`、未确认三类摘要；未知/断联不计入零值。为礼盒生成本地 pending 数，为每个 `ACTIVE` 自动化保留名称与可信状态。

**Step 2:** 添加断言：`ACTIVE` 不会变为 running、未知不会显示为 0、云端快照不伪造活动、结果 pending 计数不丢失。

**Step 3:** 运行 Node 测试，确认状态 helper 通过。
