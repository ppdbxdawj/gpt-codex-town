# 梦幻浮岛迷你模式设计

**Goal:** 将迷你模式升级为奶油马卡龙梦幻浮岛，在保持可信状态边界的前提下，用更少标签呈现最重要的提醒与可浏览的完整信息。

**Architecture:** 浮岛仍消费现有本机只读状态与 5 秒刷新，不新增云端实时来源。常驻界面只显示两类核心提醒：当前进行项与待验收结果；小院名称在 hover/focus 时完整显示。点击建筑打开短卡，通过分页查看全部进行项或待验收结果，而不是把所有文字压进场景。

**Tech Stack:** Three.js、原生 JavaScript/CSS、既有 macOS WebKit 壳与本地状态服务。

## 视觉与信息原则

- 使用奶油、粉色、薄荷与薰衣草色的浮岛、云雾、柔光和圆润建筑，保持程序化角色、工坊、小院、成果建筑和轨道的关系。
- 常驻标签最少化：工坊显示可信的进行/等待提示，成果建筑显示待验收提醒；未知、断联和云端快照均使用诚实的未确认或待更新文案。
- 小院平时只保持轻量标识；hover 或键盘 focus 后显示完整自动化名称与状态，支持长名称但不遮挡城市。
- 点击工坊或成果建筑打开短卡，分页浏览所有当前进行项或待验收结果；阅读、验收和原任务打开仍是显式操作。

## 边界

- 云端计划和结果仍是手动快照，绝不呈现为实时执行过程。
- `ACTIVE`、排期、未知和断联不能单独表示“正在运行”。
- 不修改个人角色资源或将私人数据、任务名称、截图写入公开演示资源。
